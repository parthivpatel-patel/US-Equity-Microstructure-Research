# Phase 282 — Common-date exchange admission (2026-11-10)

## Contribution
Adds a strict, standalone admission function for the exact session-by-exchange grid and fixed positive pair-count roster before descriptive estimation. It rejects missing/extra/duplicate rows, malformed dates, unordered calendars, nonfinite contrasts, boolean weights, and schema drift. The function returns Phase 278-compatible keys but **does not authenticate** its supplied calendar, SEC observations, matched pairs, or treatment assignments.

## Validation
Eleven deterministic synthetic tests passed locally on a logically equivalent implementation (Python unittest, 11 tests, zero failures). The exact GitHub checkout has not yet been rerun. No historical SEC observations were accessed and no empirical estimate or chart was generated.

## Identification warning
The substantial October 2025 placebo and September pretrends remain adverse/unresolved. Fixed exchange counts alone do not guarantee fixed security identities or independently authenticated sessions. Pair-weighted and exchange-equal estimands can differ in sign; a descriptive leave-one-exchange-out analysis is not inference. Historical estimates require SEC file hashes and definitions, dated treatment authentication, full security/pair/exchange rosters, and common-date HAC plus serial-dependence-aware resampling.
